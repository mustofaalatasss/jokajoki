# PROMPT TAHAP 0 — PASANG ATURAN PROYEK

Gunakan prompt ini pada workspace baru Google Antigravity.

---

Saya sedang membangun aplikasi bernama sementara **MABAR CTRL**, yaitu dashboard operasional Mabar VIP untuk streamer Mobile Legends.

Pada tahap ini, JANGAN membuat aplikasi dan JANGAN menulis komponen frontend.

Tugas Anda hanya:

1. Baca seluruh file di folder `docs/`.
2. Baca `.agents/skills/mabarvip-stepwise-delivery/SKILL.md`.
3. Buat `IMPLEMENTATION_PLAN.md` yang merangkum roadmap F0 sampai F5 dan menegaskan bahwa backend tidak boleh dibuat sebelum frontend selesai disetujui.
4. Buat `PROJECT_STRUCTURE.md` berisi struktur folder frontend yang akan dipakai.
5. Periksa apakah PRD, design system, dan skill konsisten.
6. Laporkan konflik atau bagian ambigu, tetapi jangan mengubah aturan bisnis tanpa instruksi saya.
7. Jangan menginstal dependency.
8. Jangan membuat proyek Next.js.
9. Jangan membuat Supabase, API, database, autentikasi, atau integrasi Saweria.
10. Setelah dokumen selesai, berhenti. Jangan melanjutkan ke Fase F1.

Keluaran wajib:

- `IMPLEMENTATION_PLAN.md`
- `PROJECT_STRUCTURE.md`
- ringkasan pemeriksaan konsistensi
- daftar pertanyaan hanya apabila benar-benar menghalangi implementasi

Berhenti setelah tahap ini selesai.
